How editing works

  1. Use the sign-in link Pages CMS emailed you. You only see the sites you've been invited to.
  2. Each site's sidebar follows the page from top to bottom, and every field says where it shows up.
  3. Click Save. The live site updates in about a minute.
  4. Keep photos under 1 MB. Every save is kept in history, so any change can be undone.
